# Notebook code exports

These `.py` files are mechanical exports of code cells from the canonical executed notebooks.

They are included for code review, searchability and archival purposes. They preserve notebook-specific orchestration, including Google Colab/Drive paths, so they are **not** the recommended reusable API and may require path/environment edits before direct execution.

Use the modules under `src/` for reusable components and the `.ipynb` files for exact executed experiment records.
